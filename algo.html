example 1.2
巢狀亂數
給亂數再加一次亂數，機率開始傾斜。均勻的點慢慢聚成漸層。
為什麼兩個 random 包起來，會變成這個形狀？

先把 random(N) 想成一台抽號機：給它一個最大值 N，它就在 0 到 N 之間隨手丟一個數字回來，每個數字的機會都一樣。

巢狀的意思是抽兩次。第一次抽出一個數字 A，把 A 當成第二次的最大值，再抽一次。第二次的範圍會被第一次卡住。

  • 第一次抽到 90，第二次的範圍是 0 到 90，還有機會抽到很大的數字。
  • 第一次抽到 5，第二次的範圍就只剩 0 到 5，怎麼抽都不會超過 5。

大數字要連中兩次籤才會出現，小數字幾乎每次都有機會。整體分布就被往「小」的那一邊拉，越靠近 0 越密集，越靠近最大值越稀疏。畫面上的點也因此從均勻變成漸層。

random(100)
0100
random(random(100))
0100
random(100) // 0 到 100，每個數字機會一樣 random(random(100)) // 第二次的最大值 = 第一次抽到的數

example 1.3
密度與空白
調整點的數量與分布，讓空白開始成為畫面的一部分。
為什麼同樣的均勻亂數，可以又密又疏？

均勻亂數本來會把點鋪滿整張畫布。要讓畫面出現空白，常用的做法是把一個點拆成兩段判斷：先選位置，再決定要不要真的畫出來。

  • 第一個 random() 決定點落在哪裡。
  • 第二個 random() 是擲一次機率骰，過了門檻才畫，沒過就跳過。

同一批候選位置，門檻設 1.0 全部畫滿，設 0.3 大約剩三成，設 0.05 只剩零星幾顆。畫面上的密度不是亂數本身變了，是「決定不畫」這個動作變嚴了。

如果再讓門檻跟位置有關，比如中心區域門檻鬆、邊緣門檻嚴，畫面就會自己長出有重心的構圖。空白不是沒東西，是被決定留下來的形狀。

門檻 1.0
全部畫
門檻 0.3
留約三成
門檻 0.05
留零星

章節六 — 常態、稀有、連續

亂數不是把控制權交出去。亂數是一種分配方式。
我不是只問：「要不要隨機？」我會問：「什麼東西應該常出現？什麼東西只偶爾出現？什麼東西需要前後連續？」
example 6.1
位置
均勻分布像星塵。Gaussian 形成重心。Perlin noise 讓位置有流動的方向。
position gaussian perlin noise
example 6.2
尺寸
平均的變化讓畫面穩定。長尾的變化讓少數物件突然變大。
scale exponential long tail
example 6.3
顏色
顏色可以在主色附近震盪，也可以偶爾抽到完全不同的色相。
color palette rare hue
example 6.4
稀缺
Rarity 不是事後貼上的標籤。它先在程式裡被安排成機率。
rarity probability feature
一個系列的性格，常常不是來自單一圖形，而是來自機率怎麼被安排。
隨機是一條可以被保存的分岔。

章節七 — Good Vibrations：把機率變成樂器

位置、尺寸、顏色、稀缺，在這裡變成一組可重播的視覺與聲音系統。
Good Vibrations 先把 token hash 轉成 seed，再讓線段、旋律、音色、metadata 從同一組亂數展開。
good vibrations 7.1
Seed
tokenData.hash 被切成數字，餵進 xorshift。Random 和 RND 每次吐出的序列都一樣。同一個 token，會回到同一張圖、同一組音。
tokenData.hash xorshift replayable
good vibrations 7.2
位置
defult() 決定 MelodyNum、線段方向、長度、位置與距離。average() 讓物件不只是散開，也會靠近某些重心。
MelodyNum average() geometry
good vibrations 7.3
稀缺
colorSetting() 把色系寫成機率。Ocean、Sunset、Forest 是常態；Cosmological 和 Monochromical 只在 rc 跨過 0.92、0.97 之後出現。
palette rc > 0.92 rc > 0.97
good vibrations 7.4
聲音
Melody 有半徑、形狀、角度、速度、亮度層與縮放層。它們在畫面中移動，和線段相交時，交點就變成聲音事件。
intersection() frqArray waveforms
