先從最簡單的 random() 開始。
機率不是把控制權交出去

我聽過一種說法：用亂數的人比較懶，「電腦在幫你決定」。這個說法把決策面看小了。

傳統繪畫的決策面是「這一筆畫在哪」。寫機率的決策面是「什麼常出現、什麼偶爾出現、什麼前後相連」。一個是物件，一個是分布。我做的事不比畫一張畫的人少，只是工作對象不同。

兩個極端都不會是作品。完全寫死，只是一張畫；完全亂數，是白噪聲，沒人會在上面簽名。藝術家在中間挑位置。挑出來的那個位置就是分布的形狀，它比任何單一張輸出更能代表我。

1960s 演算法藝術 → 2020s 生成藝術

用機率做美術不是新事。六十年前 Vera Molnár 在 IBM 主機上跑迴圈，Frieder Nake 把指令打到 plotter 上畫圖，Sol LeWitt 把規則寫在牆上讓助理執行。當代 fxhash 與 Art Blocks 上的生成藝術，是同一個母題的延續。

章節一 — 均勻亂數

點先落下來。還沒有形狀，只有機率的底色。
example 1.1
均勻亂數，「宇宙塵」
每個點都有同樣的機會出現。像一層乾淨的雜訊，還沒有方向。
random() 是什麼？怎麼讓畫面出現空白？

把 random(N) 想成一台抽號機：給它一個最大值 N，它就在 0 到 N 之間隨手丟一個數字回來，每個數字的機會都一樣。把這個動作重複幾千次去畫點，整張畫布就會被均勻鋪滿，就是這頁的基本款。

要讓畫面出現空白，最常用的做法是把一個點拆成兩段判斷：

  • 第一個 random() 決定點落在哪。
  • 第二個 random() 是擲一次機率骰，過了門檻才畫，沒過就跳過。

同一批候選位置，門檻設 1.0 全部畫滿，設 0.3 大約剩三成，設 0.05 只剩零星幾顆。畫面上的密度不是亂數變了，是「決定不畫」這個動作變嚴了。

如果再讓門檻跟位置有關，比如中心區域門檻鬆、邊緣門檻嚴，畫面就會自己長出有重心的構圖。空白不是沒東西，是被決定留下來的形狀。

全部畫

example 1.2
巢狀亂數
給亂數再加一次亂數，機率開始傾斜。均勻的點慢慢聚成漸層。
為什麼兩個 random 包起來，會變成這個形狀？

先把 random(N) 想成一台抽號機：給它一個最大值 N，它就在 0 到 N 之間隨手丟一個數字回來，每個數字的機會都一樣。

巢狀的意思是抽兩次。第一次抽出一個數字 A，把 A 當成第二次的最大值，再抽一次。第二次的範圍會被第一次卡住。

  • 第一次抽到 90，第二次的範圍是 0 到 90，還有機會抽到很大的數字。
  • 第一次抽到 5，第二次的範圍就只剩 0 到 5，怎麼抽都不會超過 5。

大數字要連中兩次籤才會出現，小數字幾乎每次都有機會。整體分布就被往「小」的那一邊拉，越靠近 0 越密集，越靠近最大值越稀疏。畫面上的點也因此從均勻變成漸層。

圓盤問題：半徑不是面積 同一個問題，我試三次。先讓半徑均勻，中心會密。再把半徑反轉，點被推到外圈。最後用 sqrt(random()) 把尺度改成面積，圓盤才接近視覺均勻。
example 1.3
圓盤問題，一：半徑均勻
角度平均繞一圈，半徑直接用 random() * R。半徑是平均的，面積不是。中心會比較擠。
第一個版本：random() * R

我先讓角度平均繞一圈，再讓半徑從 0 到 R 平均抽。這聽起來像均勻，其實只是半徑均勻。

圓盤切成內外兩塊：半徑小於一半的內圈小圓，和外面那一整圈。

  • 內圈半徑是整個圓的一半，面積只占 1/4。
  • 外圈占 3/4，因為面積跟半徑平方有關。

random() * R 會讓一半的點落在 0 到 R/2。於是一半的點擠進 1/4 的面積，中心自然變密。

function setup() { createCanvas(500, 500); noStroke(); } function draw() { background(0); for (let i = 0; i < 8000; i++) { fill(random(255)); let r = random() * width/2; let x = cos(i / 8000 * 6.28) * r; let y = sin(i / 8000 * 6.28) * r; circle(x + width/2, y + height/2, 2); } }

example 1.4
圓盤問題，二：半徑反轉
半徑先被巢狀亂數壓小，再用 1.0 - ... 反轉。點被推向外圍，圓盤變成光環。
第二個版本：1.0 - ...

角度還是平均繞一圈。我只改半徑這行：

let r = (1 - random(random(random()))) * width/2;

巢狀亂數會偏向小值，多包一層就更靠近 0。前面加上 1.0 -，小值被翻到接近 1。

  • random(random(random()))：半徑偏小，中心會擠。
  • 1.0 - random(random(random()))：半徑偏大，外圈會亮。

同一個半徑變數，反轉之後變成距離的開關。中間空出來，外圈留下來。

example 1.5
圓盤問題，三：面積尺度
sqrt(random()) * R 把半徑往外補。不是為了做光環，而是讓每一圈拿到和面積相稱的點。
第三個版本：sqrt(random()) * R

角度不變，半徑換成這一行：

let r = sqrt(random()) * width/2;

sqrt 不是裝飾。它把半徑往外補，補到剛好符合面積的成長。

  • random() * R：一半的點進到半徑一半的內圈，中心偏密。
  • sqrt(random()) * R：只有 1/4 的點進到那個內圈，剛好對上 1/4 的面積。

這三張圖其實是一個半徑問題：

  • random() * R：半徑均勻，中心密。
  • 1.0 - ...：半徑反轉，外圈亮。
  • sqrt(random()) * R：面積修正，圓盤均勻。
random() × R

sqrt(random()) × R
整個圓盤均勻

example 1.6
視覺均勻，Blue Noise
純 random 會自然結團。Poisson disk 在點和點之間加上最小距離，畫面看起來更均勻。這不是更「隨機」，而是更接近人眼期待的均勻。
視覺均勻 ≠ 機率均勻

每個點獨立落下來，局部就會有擠在一起的時候。那是真正的隨機，不是程式壞掉。

Poisson disk 多加一條規則：新點不能離舊點太近。點還是從機率裡長出來，但彼此保留一點空氣。畫面少了結團，多了一種細密的平均。

這種分布常被叫做 blue noise。它不是把亂數變乾淨，而是把人眼不想看的低頻結團壓下去。

Rejection Sampling — 另一條把點均勻撒進圓盤的路
1.5 用 sqrt 修正面積偏差，但其實還有更直觀的解法：在方框內均勻撒，超出圓的丟掉。對照兩種思路。
目標
介紹 rejection sampling 作為通用工具：先在簡單區域均勻撒，再過濾。為章節六 6.7 鋪墊。
內容大綱
  • 方法：在 [-R, R] × [-R, R] 正方形內撒點，x² + y² > R² 的就 reject
  • π/4 ≈ 78.5% 通過率，浪費的點佔 21.5%
  • 優點：思路直觀、可推廣到任何「先大區域，後過濾」的形狀
  • 缺點：浪費點、形狀越複雜通過率越低
  • 對照 1.5 的 sqrt（inverse CDF）：精確不浪費，但要算數學
  • 什麼時候用哪個：形狀簡單可解析 → inverse CDF；形狀複雜不可解析 → rejection

  x = random(-R, R);

Perlin 其實不是隨機 — Deterministic Gradient Noise
章節三只說「前一刻會影響下一刻」，沒講 Perlin 本質：給同一個 x 永遠回同一個值。這是它能被當成「材料」的關鍵。

Frequency、Amplitude、Octave — fBm 分形布朗運動
Perlin 一次叫只給「中等尺度」的擾動。把多個尺度疊加才會出現自然紋理（雲、山、火）。這是 generative artist 每天用的招。

}

噪聲的美學光譜 — White / Pink / Brown / Blue Noise
