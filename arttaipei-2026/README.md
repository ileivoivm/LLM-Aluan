# 一條路徑，長成一座森林
## A Path That Grows Into a Forest

王新仁（阿亂 / Aluan Wang）｜ART TAIPEI 2026 第五場藝術講座「科技與藝術之間：創作、感知與新經驗」

**Live →** [投影片](https://ileivoivm.github.io/LLM-Aluan/arttaipei-2026/) · [PDF](./aluan-arttaipei-2026-slides.pdf) · [口說稿](./speaker-notes.md)

## 主線

讓作品超越一個藝術家的意志，成為集體意志的藝術。

19 頁，約 24 分鐘。現場是藏家、畫廊與藝術家。

| 段落 | 頁 | 內容 |
|---|---|---|
| 開場 | 01–05 | 自我介紹、面對 AI 的三種態度、當畫面變得容易、集體意志 |
| 創作 | 06–08 | 一條貫穿的路徑、《植徑集》、藝術家是系統建構者，觀眾是園藝師 |
| 參與 | 09–13 | COMPUTEX × ART TAIPEI《植徑集——共生之鍊》、30 秒的參與設計、作品跟他們有關係 |
| 行動 | 14–16 | 《墨域 inkField》保存畫的過程、算力可以造假、《前往美術館的路上》 |
| 收尾 | 17–19 | 收藏端的參與（objkt Kento）、四個轉變、集體意志的藝術 |

## 使用方式

- 打開 `index.html` 即可放映。← → 換頁，「總覽」看全部縮圖。
- 「講稿」按鈕（或鍵盤 N）打開右側口說稿，含每頁建議時間與轉場句；「計時」可以練習抓時間。
- 列印或輸出 PDF 時，講稿與影片不會出現，影片頁自動改為靜態畫面。

## 檔案

```
arttaipei-2026/
├── index.html                          # 投影片（含講稿面板）
├── speaker-notes.md                    # 口說稿（內容來源）
├── aluan-arttaipei-2026-slides.pdf     # PDF 版
└── assets/                             # 圖片與影片
```

`speaker-notes.md` 是口說稿的內容來源；`index.html` 裡的講稿面板內容由它產生，改講稿時先改 `.md`，再同步到 HTML。
