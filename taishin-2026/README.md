# 成為培養皿的園藝師
## The Gardener of a Petri Dish

王新仁（阿亂 / Aluan Wang）｜台新藝術基金會「跨域的十二夜」第二番：AI 算力與個體意識的創作協同｜2026.11.11

## 主線

培養皿是一個有邊界的小世界：溫度、養分、規則由藝術家決定，裡面長出什麼，不完全由他決定。園藝師不製造植物，他做的是看、留、剪。

19 頁，約 20 分鐘，分三段：

| 段落 | 頁 | 內容 |
|---|---|---|
| 開場 | 01–05 | 工作現場、Web3 與 AI 兩股力量、《植徑集》、COMPUTEX《共生之鍊》 |
| 勞動與作品 | 06–15 | agent 的研究（191 頁索引、房屋解構、頭像多樣性）、AI 擴充了什麼、勞動變成勞心、人體校正台、自己選擇限制、《墨域》的真實時間、從 AI 那一側看、被執行 |
| 收束 | 16–19 | 指令還在作品就能繼續長、把培養皿留在自己手上、園藝師也住在培養皿裡、收尾 |

第 14、18 頁「從 AI 那一側看」，是講座當天早上請 Claude 以非人類的角度重讀日記與作品後提出的觀點。

## 使用方式

- 打開 `index.html` 即可放映。← → 換頁，「總覽」看全部縮圖。
- 「講稿」按鈕（或鍵盤 N）在投影片下方打開逐字稿，含每頁建議時間與轉場句；「計時」可以練習抓時間。
- 影片都是作品的實際操作錄影（無聲、自動重播）。

## 檔案

```
taishin-2026/

├── speaker-notes.md    # 口說稿（由 index.html 匯出）
```
